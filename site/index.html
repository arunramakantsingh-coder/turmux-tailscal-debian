Fresh phone provisioning

This is the front door for a new Android phone. Android installation is the only manual security boundary.

  1. Tap Download & Install Termux below.
  2. Android downloads the official Termux APK.
  3. Open the downloaded APK and approve the Android installation.
  4. Open Termux once, then run the provisioning command below.
  5. The bootstrap handles the remaining setup.
Install Provisioner

Provisioner v0.3.0-alpha.1 • Termux v0.118.3 stable • official GitHub source

One-command provisioning

curl -fsSL https://raw.githubusercontent.com/arunramakantsingh-coder/turmux-tailscal-debian/main/bootstrap/install.sh | bash

QR

Scan this page URL to reach the provisioning page on the phone.

Android security boundaries: the Provisioner cannot silently bypass Android's installation approval. After Termux is installed, the first test will open Termux and place the bootstrap command in the clipboard. Full zero-touch command execution requires the Termux RUN_COMMAND permission plus allow-external-apps=true, both intentionally protected by Termux.

What the bootstrap installs

Termux tools, Tailscale userspace networking, SSH, proxy support, Debian via proot-distro, and Debian development/networking tools.
