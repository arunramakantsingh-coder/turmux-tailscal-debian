Android Development Appliance

Custom Termux core + Tailscale userspace + Debian • Model 1 • v0.5.0-alpha.5

One APK → automatic provisioning

The separate Provisioner POC has been replaced. This APK is the appliance itself, built from the official Termux v0.118.3 source with a narrowly scoped first-session provisioning hook.

Download Appliance APK

Fresh-phone flow

  1. Download the APK.
  2. Approve Android's installation prompt.
  3. Open Android Development Appliance.
  4. The first terminal session launches the provisioning flow. On first run it asks once for your private Tailscale auth key (tagged AuthkeyNodes), then provisioning continues automatically.
  5. Termux packages, Tailscale userspace, Debian, SSH, proxy support and the local operations page are configured automatically.
  6. Tailscale uses the locally supplied auth key. Browser/QR authentication is not used in the normal provisioning path.

After provisioning

Run appliance-status or open http://127.0.0.1:8080.

SSH: Termux 8022 • Debian 2222 • SOCKS5 1055.

Manual recovery

curl -fsSL https://raw.githubusercontent.com/arunramakantsingh-coder/turmux-tailscal-debian/main/bootstrap/install.sh | bash
Android boundary: stock Android still requires user approval for sideloading an APK. After that approval, this appliance performs the Termux/bootstrap phase itself. No ADB and no external RUN_COMMAND companion app are used.

Security

No Tailscale auth key or SSH password is embedded in this public page or repository. SSH passwords are generated locally on the device. The Tailscale auth key is entered once locally, stored with mode 600, and deleted after successful authentication. It is never embedded in this public repository, Pages site, or APK.
